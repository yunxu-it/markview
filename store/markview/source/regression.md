本文件用于手动验收，不代表已运行验证。请使用更新后的 `markdown-preview` 源码加载扩展。

发布前可先按 [打包说明](../README.md) 生成 ZIP，解压加载后执行以下清单，检查包内入口、双语资源、项目 MIT 许可及 Bear 许可完整。素材入口使用演示 API，不能代替新包安装、真实文件选择、原生目录授权、跨标签 PDF 消息和最终 PDF 文件验收。

## 文件入口与阅读连续性

1. 直接打开本文件，确认自动预览和目录跳转正常。
2. 点击目录标题栏「打开」，选择「打开文件」并打开本文件；再次选择同一个文件也应生效。菜单还能选择「打开文件夹」；Esc 或点击外部应收起菜单，两个入口都需由用户点击后调用对应选择器。
3. 取消文件选择，当前文档应保持不变。
4. 拖入本文件，确认原有拖拽入口可用。
5. 点击上述 HTTPS 链接，应在新标签打开，原页面仍保留文档。
6. 选择文件后，相对路径图片限制提示应继续显示。

## 文件夹浏览与文档切换

1. 准备一个含根目录文档、嵌套子目录、两个不同目录下的同名 Markdown，以及图片、文本文件的文件夹。加入 `.MD`、`.markdown`、`.mdown` 后缀及带中文、空格、& 和括号的文件名。
2. 打开一份文档后，通过「打开 → 打开文件夹」授权所在目录，自动切到文件视图。原生目录方式不能调用上传选择器，不请求写权限；若 `file://` 页面拒绝接口，应提示进入扩展预览页再试。只手动点击「兼容方式选择文件夹」时才出现 Chrome 的“上传”确认，并解释仅本地处理。
3. 授权后保留正文，并关联当前文档：原生选择文件按句柄定位，直接打开文档按目录相对路径和内容匹配，普通选择或拖入文档仅唯一名称及内容匹配时标记，不能误选同名文档。目录树只列 Markdown，保留层级、目录优先且数字自然排序，名称按文本显示。点击文件更新正文、页面标题、当前标记和章节树；切到「章节」后只能看到章节树，切到「文件」后只能看到文件树，文件树折叠状态与各视图滚动位置保留。切换文档后章节搜索应清空，无标题文档的搜索框应禁用。
4. 快速点击多个文件或在读取期间改选文件夹，旧文件读取完成后不能覆盖最后的选择。模拟读取或渲染失败时，保留当前正文和当前文件标记并显示失败提示。
5. 取消选择或选择没有 Markdown 的文件夹，应保留当前文档和已有文件列表；后者提示没有 Markdown。再次选择同一文件夹应更新列表。
6. 分别滚动两个不同子目录的同名文档，交替切换时应各自恢复位置；重新选择相同目录后点击相同路径且内容未变的文档也应恢复。`chrome.storage.local` 不能出现原始文件名、相对路径、目录列表或正文；IndexedDB `markview-folders` 仅保存最近目录句柄，不保存文档或文件列表。
7. 原生只读模式修改文件后，再次点击文件应读取最新内容；兼容方式修改文件后需重新选择。新增、删除文档后重新选择目录，或刷新恢复目录，应更新列表。刷新后权限有效就自动恢复文件树，不再弹选择器；权限失效只显示「继续读取文件夹」，点击仅申请 `read`，不用重选目录。拒绝授权应保留当前文档；存储不可用时仍能浏览当前选择。相对图片和跨文档相对链接仍需通过直接打开原始文件查看。
8. 用 Tab 聚焦文件夹和文件，Enter/Space 展开目录或打开文档；「跳到正文」应能跳过文件列表并聚焦正文。小窗口点击文件后应收起侧栏，展开后仍可切换；打印不能显示文件导航或跳到正文入口。
9. 文件夹选定后，选择单个文件或拖入文档仍应有效：如果能唯一关联到目录内的文档，应更新当前标记并展开父目录；否则清除当前标记，保留已有树供用户选择。重新点击列表内文件应恢复标记。原生选择文件后，再授权所在目录，选择器应从该文件所在目录开始。
10. 文档标题为 `open-menu`、`open-folder`、`folder-input`、`files-section`、`folder-name`、`files`、`view-files`、`view-chapters`、`chapters-section`、`files-hint`、`folder-fallback`、`resume-folder`、`forget-folder` 时，应生成不同的章节 ID，文件夹控件和章节跳转仍可正常使用。
11. 「打开 → 忘记文件夹」应清除保存的句柄和文件树，保留正文，磁盘文件不变；刷新后不能自动恢复该目录。存储恢复期间若重新选目录或忘记目录，旧恢复结果不能覆盖用户选择。连续选目录和忘记目录后，最终持久记录应与最后操作一致。

## 侧栏图标与箭头样式

1. 「打开」应显示线条文件夹图标及向下箭头，展开后箭头向上；菜单选项和 Esc、外部点击收起仍正常。
2. 「章节 / 文件」应显示图标及浅灰分段底色，当前视图白底高亮；图标不重复朗读，键盘焦点清晰，切换状态仍通过 `aria-pressed` 表达。
3. 章节树和文件树的箭头应与整行内容垂直居中，长标题换行后也不偏到顶部；折叠时向右，展开时向下，目录折叠、章节链接跳转和当前章节高亮仍有效。

## 侧栏宽度

1. 拖动目录右边缘，目录和正文应同步调整，松开后停止调整。
2. 刷新或打开其他 Markdown 文件，应恢复保存的宽度。
3. 缩小再放大窗口，侧栏应适配可用空间，并恢复原先的宽度偏好。
4. 双击分隔线应恢复默认宽度，刷新后仍使用默认值。
5. 用 Tab 聚焦分隔线，方向键应微调宽度，Home/End 调到边界，Enter 恢复默认。
6. 收起目录后分隔线应隐藏，展开后恢复；打印时分隔线不应出现。

## 侧栏展开/收起记忆

1. 没有 `sidebarHidden` 设置时，首次打开应默认展开目录。
2. 点击“收起目录”，刷新或重新打开本文件，侧栏和分隔线应保持隐藏，展开按钮可用。
3. 点击展开按钮，再刷新或打开其他 Markdown 文件，侧栏应保持展开，并恢复保存的宽度。
4. 在小窗口点击目录标题自动收起后，刷新应仍保持收起；展开后应显示当前高亮章节。
5. 在偏好读取完成前切换侧栏，异步读取不应覆盖刚选择的状态；自动恢复不应抢走键盘焦点。
6. 收起侧栏后滚动正文，刷新时应在恢复侧栏状态后恢复阅读位置；目录搜索和代码复制仍可正常使用。
7. 存储读取或写入失败时，仍可正常展开和收起侧栏；没有有效布尔值时默认展开。

## 目录高亮与代码复制

1. 快速向下、向上滚动，目录应高亮页面上方正在阅读的章节；同一长章节内不应跳到其他章节。
2. 折叠父目录，再滚动进入其子章节，父目录应自动展开；停留当前章节时应允许手动折叠。
3. 滚动到页面底部，最后一个章节应高亮；点击目录或刷新带锚点的地址后，应同步定位和高亮。
4. 改变窗口或侧栏宽度，目录高亮应根据新的排版更新。
5. 悬停下面的代码块或用 Tab 聚焦复制按钮，点击后粘贴到文本编辑器；中文、缩进、换行、尖括号和引号应保留，不能包含按钮文字或 HTML 高亮标签。
6. 多个代码块的复制反馈应互不影响；无剪贴板访问能力时应提示失败，支持再次尝试。
7. 横向滚动长代码，复制按钮应留在代码块右上角；打印时不显示按钮。

## 阅读位置记忆

1. 直接打开本文件，先移除地址中的 `#章节`，滚动到中部，停留片刻后刷新，应恢复原来的阅读位置；对应的高亮目录项应自动滚入侧栏可见区域，正文位置不应被二次改变。
2. 为两个不同路径的文件分别滚动到不同位置，重新打开时应各自恢复，不能互相覆盖。
3. 使用带 `#章节` 的地址打开本文件，应优先定位章节，不恢复之前记录的滚动位置；长目录也应同步滚到该章节。收起侧栏、继续阅读后再次展开，应显示当前高亮目录项。
4. 在恢复完成之前主动滚动或操作页面，异步读取完成后不应把页面拉回旧位置。
5. 选择或拖入本文件并滚动，切换到其他文件，再重新选择同名且内容相同的本文件，应恢复位置；修改内容后视为不同文档。
6. 在扩展存储中检查数据，应仅看到侧栏宽度、数值 `articleMaxWidth`、布尔值 `sidebarHidden`、字符串 `theme`、语言标识 `language` 和 `readingPosition:` 加哈希的记录；language 仅为 auto / zh-CN / en，位置记录只包含滚动数值和最近使用时间，不包含原始路径、文件名或文档内容。
7. 打开超过 200 份不同文档后，等存储请求完成，位置记录应最多保留 200 条；重新访问过的文档应比更久未使用的文档晚淘汰。
8. 在多个标签页交替打开和滚动不同文档，待请求完成后，记录数仍应不超过 200；侧栏宽度设置不应被清理。
9. 使用旧版只有 `top` 字段的数据，重新打开对应文档应恢复位置并补充使用时间；若已有超过 200 条旧记录，下次访问应自动清理，保留当前文档。

## 目录搜索

1. 输入“复制”，仅保留匹配标题及其父级路径，显示匹配数量。
2. 输入不存在的标题，应显示“没有匹配的标题”；清空或按 Esc 后恢复完整目录和之前的折叠状态。
3. 按 Enter 跳转第一个匹配标题；中文输入法确认候选词时不应触发跳转。
4. 搜索期间滚动正文，自动高亮不应展开无关目录；点击搜索结果仍应正常定位。
5. 切换到另一份文件，搜索条件应清空；无标题文档的搜索框应禁用。

## 渲染失败兜底

在开发调试环境中模拟解析器抛出异常：首次直接打开文件应保留原始内容并显示失败提示；已有文档时再次选择或拖入文件，应保留当前文档并提示渲染失败。此项需要主动模拟异常，普通示例内容不会触发。

## 当前文档导出 PDF

1. 点击扩展图标，在设置弹出页选择「打开预览页」进入欢迎页，再点击图标，「导出 PDF」应禁用并提示打开文档；侧栏不能再出现导出按钮。直接打开、选择、拖入或从文件树切换到 Markdown 后，再打开弹出页应启用导出。空文件仍可导出，文件读取失败时保留上一份文档的导出能力。
2. 点击弹出页「导出 PDF」，弹出页关闭并打开正文页打印预览，不能打印弹出页本身。在打印预览中选择「另存为 PDF」，预览应包含整份当前正文，隐藏侧栏、展开按钮、状态提示和代码复制按钮；收起侧栏后使用 Ctrl+P 应采用相同打印样式。
3. 导出包含中文、链接、任务列表、长代码行、宽表格及多页正文的文档，检查 PDF 文字可选择和搜索、代码保留缩进并换行、表格没有横向裁切。检查标题与后续内容的分页；超宽表格可使用横向纸张或调整缩放。
4. 直接用 Chrome 打开含可访问本地图片的文档，等待图片加载完成后导出，确认图片保留。通过选择文件或文件树打开时，沿用原有相对图片限制。
5. 取消打印后，正文、侧栏开关与折叠状态、阅读位置应保持；切换另一份文档再次导出，内容应随之更新。保存 PDF 后打开文件检查分页、图片和全文，不能仅以打印窗口出现视为通过。
6. 同时打开两份 file:// 文档和两份扩展预览页，分别从当前标签页导出，只能触发当前页，其他页不能响应。切到普通网页，即使后台仍有文档，弹出页也应禁用导出；页面未就绪、已导航或扩展重载后连接失效时，应禁用或提示刷新重试，不能改为导出另一页。

5. 缩窄窗口和拖动侧栏宽度，检查设置面板及控件不溢出。每套主题分别使用「导出 PDF」或 Ctrl+P 检查字体、配色和标题排版；打印时不保留屏幕版心宽度限制。深色背景以浏览器打印设置为准，书卷报告应保持白底黑字，正文为 11pt / 1.6 倍行距；表头、引用和链接下划线应可辨识，主标题与章节的对齐方式正确。
