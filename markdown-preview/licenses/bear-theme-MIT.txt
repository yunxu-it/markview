Bear Theme with Typora - adapted for MarkView
Source: https://gist.github.com/Kenshin/e5adc79da3149315bdfd72a35b70d65e
Source revision: 4f51ed827eb2ceb2eedce1a92111d61ca09f711a
License source: https://github.com/Kenshin/mduikit/blob/master/LICENSE
Additional visual reference: https://theme.typora.io/theme/Bear/
Palette and layout reference: https://github.com/imageslr/mweb-themes

MarkView adapts the Bear palette, red list markers and blockquote accent
to its existing preview DOM. The current layout and lexer are independently
implemented, referencing the imageslr Red Graphite palette and code metrics.
Code uses a white surface, thin border, monospace font and semantic colors.
Interactive red text uses a darker shade for readability. Fonts use local
system fallbacks, and reading width remains controlled by the user's setting.
