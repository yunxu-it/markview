# 墨览 · MarkView

当前 manifest 版本：1.3.0。截至 2026-10-21，[Chrome 商店](https://chromewebstore.google.com/detail/ehpgkiagfgnbbmcfeemceglgfbojmcbk)已公开发布 1.3.0，与本仓库源码版本一致。以下功能与使用说明对应 1.3.0；五套阅读主题、正文宽度设置、中英双语界面和 PDF 导出入口为此版本新增功能。打包方法、1.3.0 界面截图和隐私政策见 [项目资料](../store/markview/README.md)。

无需构建、无需外部依赖的 Chrome Manifest V3 扩展。

## 安装

### Chrome 商店安装

前往 [墨览 · MarkView 商店页面](https://chromewebstore.google.com/detail/ehpgkiagfgnbbmcfeemceglgfbojmcbk) 安装。当前商店提供 1.3.0，实际可安装版本以商店页面为准；安装后如需直接预览本地文件，请在扩展「详情」中开启「允许访问文件网址」。

### 源码加载（1.3.0）

1. 打开 `chrome://extensions`，开启右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `markdown-preview`。
3. 在扩展「详情」中开启「允许访问文件网址」。
4. 将 `.md` 文件直接用 Chrome 打开，即可自动预览。修改文件后刷新页面即可。

点击扩展图标弹出阅读设置，可调整界面语言、主题和正文最大宽度；点击面板中的「打开预览页」进入阅读页面，再选择或拖入 Markdown 文件。

侧栏使用统一的「打开」入口，展开后可选择「打开文件」或「打开文件夹」；菜单支持键盘操作，Esc 或点击外部收起。通过「章节 / 文件」切换同一块导航区域：「章节」显示当前文档标题树和搜索，「文件」显示目录中的 Markdown。打开文件夹自动切到文件树，仅请求读取权限，不调用“上传文件”选择器；浏览器仍可能显示目录访问授权。若当前页面拒绝目录接口，可点击扩展图标，再选择「打开预览页」重试；只有手动点击「兼容方式选择文件夹」才使用原来的目录选择器，并提示 Chrome 会出现“上传”确认。

授权成功后保留当前正文，自动尝试关联并高亮当前文档。扩展预览页原生选择的文件按文件句柄精确定位；直接打开的文档按目录相对路径及内容匹配，普通选择或拖入的文件仅在名称、内容唯一匹配时关联，同名文档无法确定时由用户点击文件树选择。目录及子目录列出 `.md`、`.markdown`、`.mdown`（不区分大小写），仅显示含 Markdown 的分支；目录可折叠，目录优先、名称按自然顺序排列。点击文件切换正文和章节树，视图、文件树折叠状态保留；小窗口切换后自动收起侧栏。取消授权、目录读取失败或没有 Markdown 时保留正文和已有文件树。

只读模式在当前页面来源的 IndexedDB（`markview-folders`）记住最近一次成功打开的目录句柄，可通过句柄取得目录名称；不保存正文、文件列表或完整磁盘路径，不上传。刷新或重新打开时，读取权限仍有效就重新枚举目录、恢复文件树；权限失效时显示「继续读取文件夹」，点击重新授权即可，无需再次选择目录。不会在页面加载时自动弹授权框；可通过「打开 → 忘记文件夹」删除句柄及当前文件树，不删除磁盘文件。忘记目录不代替浏览器权限设置中的撤销授权。扩展预览页共用目录记忆，`file://` 页受浏览器来源与接口限制，不保证与扩展预览页共享记忆；建议从扩展图标进入预览页使用。

文件列表和正文仅保留在内存中。目录增删后可重新打开目录更新列表；刷新恢复时也会重新枚举。只读模式每次点击文档读取最新内容，兼容模式仍需重新选择目录以更新内容，且不保存目录句柄。为关联已有文档，必要时读取名称唯一匹配的候选正文。不同子目录下的同名文档使用相对路径和内容生成阅读标识；相同路径且内容未变时可恢复阅读位置。不同磁盘位置的同名目录若相对路径及内容都相同，会共用阅读记录。

目录标题栏的「打开」菜单可选择文件或文件夹。拖动侧栏右边缘可调整宽度（通常为 200–600px，小窗口按可用空间限制），双击恢复默认宽度；分隔线获得键盘焦点后支持方向键微调、Home/End 调到边界、Enter 恢复默认。

侧栏宽度、正文最大宽度、整个侧栏的展开/收起状态、主题、界面语言和各文档的阅读位置通过 `chrome.storage.local` 保存在本机。侧栏状态在所有文档间共用，刷新或重新打开时恢复，首次使用默认展开；小窗口点击目录标题后自动收起的状态也会保存。恢复期间若已切换侧栏，则保留刚选择的状态。直接打开的文件以去除锚点后的地址生成 SHA-256 标识；选择或拖入的文件以文件名和内容生成 SHA-256 标识。存储中仅保存侧栏宽度、正文最大宽度、侧栏状态、主题标识、语言标识、哈希标识、滚动数值和最近使用时间，不保存原始文档内容、文件名或完整路径。

阅读位置最多保留最近使用的 200 份文档，每次打开或保存位置都会更新使用顺序，并清理最久未使用的记录。旧记录在下一次读取或保存时纳入清理，没有使用时间的记录优先淘汰；侧栏宽度设置不受影响。

没有章节锚点时，刷新或重新打开文档会尝试恢复阅读位置；带锚点时优先定位章节。恢复期间如果已经手动操作页面，就保留当前阅读位置。拖入或选择的文档需要重新打开同名且内容相同的文件才能恢复，其内容不会自动保留。修改文档或图片加载导致排版变化时，按原滚动位置恢复可能存在偏差。

## 功能

- 「界面语言 / Interface language」可选择跟随浏览器、简体中文或 English。默认跟随 Chrome 界面语言，中文语言环境使用简体中文，其他环境使用英文；手动选择优先，保存为 language: auto / zh-CN / en，刷新后恢复并同步到已打开的预览页。覆盖设置页、主题名称、侧栏、复制状态、搜索数量、权限与错误提示、欢迎页及无障碍标签，更新页面 lang；文档正文、文档标题、文件名和代码原文保持原样。英文主题依次为 Classic Light、Warm Paper、Soft Dark、Serif Report、Crimson Minimal。
- 扩展图标弹出「阅读设置」，可选择经典明亮、暖纸阅读、柔和深色、书卷报告、绯红简约；侧栏不再包含设置入口。首次使用经典明亮，已打开的预览页实时同步设置，刷新或重新打开时恢复上次选择；保存失败会显示提示。五套主题沿用原有 github、warm、dark、report、bear 标识，只调整显示名称，已有偏好继续生效。
- 经典明亮保留 GitHub 风格的白底、蓝色链接、16px 正文和 1.6 倍行距，补齐函数、变量、属性、类型等代码配色，适合技术文档。
- 暖纸阅读采用米白背景、17px 正文和 1.78 倍行距，配合暖色代码框、浅底引用及横向表格分隔，减少长文阅读时的空散感。
- 柔和深色使用暗色侧栏、低亮度代码底色和完整的柔和代码配色；悬停与选中使用不同底色，当前文件和章节增加侧边标记，键盘焦点使用独立浅蓝轮廓。
- 书卷报告使用系统衬线字体和灰阶代码配色，无需下载字体。仅文档第一个元素为一级标题时居中显示该主标题，后续章节左对齐；完善表头、引用、链接下划线与代码字重层次，打印正文使用 11pt 和 1.6 倍行距。
- 绯红简约原名「Bear · 熊掌记」，保留按 [imageslr 的 Typora Bear](https://theme.typora.io/theme/Bear/) / Red Graphite 参考独立适配的排版：近白背景、红色链接与列表标记、细红引用线、无横线标题和 1.68 倍正文行距；一级至四级标题按默认 16px 正文呈现 26/22/20/18px 层级。保留白底细边框、10px 内边距、3px 圆角代码框及蓝色关键字/函数、棕红字符串/参数、紫色属性/运算符、青蓝变量。原有 Kenshin 主题适配的版权与 MIT 许可保留在 [licenses/bear-theme-MIT.txt](licenses/bear-theme-MIT.txt)，不加载远程主题或字体。
- 五套主题的代码块统一采用 14px 等宽字和 1.6 倍行距，除绯红简约为 10px 内边距外，其余均为 12px；复制按钮单独占列，移除原有 44px 顶部占位，长行仍可横向滚动。打印时隐藏按钮并恢复完整代码宽度、长行换行与分页。普通文件项融入各自的侧栏背景，悬停、选中与键盘焦点分别反馈。
- 图标弹出面板内拖动「正文最大宽度」，可在 480–1600px 间按 20px 调整，最右侧为「铺满 / Full width」。拖动即时保存并同步到已打开的预览页；宽度独立于主题，在文档间共用，小窗口自动适应可用空间。默认铺满，「恢复默认 / Reset」恢复经典明亮、铺满宽度和跟随浏览器语言；点击面板外部或 Esc 关闭，再次打开会恢复已保存的值。面板内保留「打开预览页」入口，无需新增权限。
- H1–H6 标题树、章节跳转、节点折叠、收起/展开侧栏；无顶部工具栏。
- 章节树与文件树切换、只读目录授权、子目录折叠和 Markdown 切换，显示当前文件及相对路径；支持键盘操作和跳到正文。
- 统一打开菜单、目录记忆与刷新恢复；读取权限失效时一键重新授权。
- 目录按正文阅读位置高亮当前章节，切换章节时自动展开其父目录。
- 目录搜索按标题过滤并保留父级路径；Enter 跳转第一个匹配标题，Esc 清空，清空后恢复搜索前的折叠状态。
- 代码块悬停或键盘聚焦时显示复制按钮，复制纯代码文本并提示结果。
- 打开文档后点击扩展图标，在弹出面板中选择「导出 PDF」，关闭面板并打开当前标签页正文的打印预览，再选择「另存为 PDF」保存；侧栏不再包含导出入口。普通网页、欢迎页或尚未就绪的预览页禁用导出并显示提示；不会导出其他标签页中已打开的文档。打印隐藏侧栏、状态提示和复制按钮，支持代码长行换行、表格换行和分页。
- 常用标题、粗体、斜体、删除线、行内代码、围栏代码块与分语言词法着色、表格、列表、任务列表、引用、链接和图片。代码着色支持常见 JS/TS、Kotlin/Java 等 C 风格语言，以及 PowerShell、Shell、Python、JSON、YAML、SQL、HTML/XML、CSS；补充函数、变量、属性、参数/注解、类型、运算符等类别，字符串和注释优先整体识别。
- 直接打开本地文件时，图片和链接以原文件路径为基准解析。
- 文档内容仅在本地处理；原始 HTML 按文本显示，禁止脚本链接。

## 使用边界

- 扩展管理页名称、描述和浏览器工具栏悬停标题通过 Chrome 本地化资源跟随浏览器语言；弹窗内的手动语言选择作用于 MarkView 页面，不修改浏览器或扩展管理页语言。当前仅提供简体中文和英文，浏览器原生选择器、权限提示与打印界面的语言由浏览器控制。界面词条内置于 i18n.js，扩展元数据位于 _locales，无需网络、远程翻译或新增依赖；规则参考 [Chrome i18n 文档](https://developer.chrome.com/docs/extensions/reference/api/i18n)。
- 内置轻量解析器覆盖常用语法，不承诺完整 CommonMark / GFM 兼容性；暂不支持数学公式、Mermaid、引用式链接。代码高亮是轻量词法识别，不是完整语言解析器，复杂正则、嵌入语言及模板表达式等可能只部分着色；未声明或未知语言按纯文本显示。高亮不执行代码，复制仍取代码原文。
- 选择文件、选择文件夹及拖拽受浏览器保护，无法取得原始完整磁盘路径，因此不支持解析相对路径图片和跨文档相对链接。需要本地图片或相对链接时，请直接打开 `file://` 下的原文件。
- 不会持续监控磁盘变更。直接打开的文档修改后需刷新，拖入文档需重新拖入；原生目录模式每次点击文档读取最新正文，目录增删后重新打开目录或刷新恢复文件树，兼容模式需重新选择。
- 自动预览匹配 `.md`、`.MD`、`.markdown`、`.mdown` 后缀。
- PDF 通过浏览器原生打印保存，需在预览中确认保存位置；可选择纸张、方向、缩放，并按需关闭页眉页脚。导出沿用当前主题的配色、字体和标题排版，版心适应纸张；正式分享可先切换为书卷报告，浏览器打印设置可能覆盖背景颜色。导出沿用当前预览的内容与图片访问限制，建议等待图片加载完成后操作；超宽表格可改用横向纸张或调整缩放。
